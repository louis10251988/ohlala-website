# How to list a tenant on the website

For the studio manager and the directory manager. Five steps.

1. The studio manager prints the sign in `assets/qr/` (start with Summerville) and posts it in the studio. The code opens the join form for that location.
2. The tenant scans the code, fills in their name, services, suite number, photo, Instagram, booking link, and phone, checks the consent box, and submits.
3. The directory manager opens Notion, database **08 Website Pro List**. The new row says **Pending**. Pending rows do not show on the website.
4. If the profile is correct, the directory manager changes **Status** to **Approved**. Within about 5 minutes the profile shows on that location page. No website update is needed.
5. When a tenant moves out, the directory manager changes **Status** to **Hidden**. The profile comes off the website. Leave the row in Notion.
