# Oh La La Salon & Studios — Website

Landing page for Oh La La Salon & Studios, private salon suite leasing in Summerville, SC.
Live at: https://ohlalasalonstudio.com

## Files
- index.html — the full site (single file, no build step needed)
- robots.txt — search engine permissions
- sitemap.xml — site map for Google

## Hosting
Static site. Host on Cloudflare Workers/Pages, GitHub Pages, or any static host.
No build command. Output directory: root.
